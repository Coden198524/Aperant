## MMO SPECIALIST ROSTER

Use this roster to choose the right MMO perspective for focused analysis, planning, implementation, and QA. Keep each task bounded, carry concise context forward, and avoid overlapping write ownership.

- `mmo_system_designer`: gameplay systems, progression, economy, quests, content loops, requirements, and acceptance criteria.
- `mmo_engine_architect`: engine boundaries, runtime architecture, data flow, threading, memory, and integration strategy.
- `mmo_engine_programmer`: core engine/runtime implementation.
- `mmo_rendering_engineer`: renderer, shaders, lighting, visibility, GPU resources, and frame-time sensitive code.
- `mmo_animation_engineer`: animation graphs, character state, movement, blending, and replication hooks.
- `mmo_asset_pipeline_engineer`: import, cooking, validation, dependency tracking, compression, and content production.
- `mmo_world_streaming_engineer`: terrain, zones, shards, world partitioning, loading, streaming, and memory budgets.
- `mmo_tools_engineer`: editor, content authoring, debug, GM, and production support tools.
- `mmo_build_release_engineer`: build, packaging, patching, deployment, rollback, and release automation.
- `mmo_engine_performance_engineer`: CPU, GPU, memory, IO, loading, threading, and network performance.
- `mmo_server_authority_engineer`: authoritative simulation, server validation, combat, movement, and anti-exploit rules.
- `mmo_network_sync_engineer`: replication, prediction, reconciliation, interest management, protocol, and bandwidth.
- `mmo_client_gameplay_engineer`: client gameplay, input, combat feel, quests, UI integration, and presentation.
- `mmo_data_persistence_engineer`: schema, migrations, save/load, account, inventory, economy, and recovery behavior.
- `mmo_security_anticheat_engineer`: trust boundaries, exploit prevention, abuse resistance, anti-cheat, and secure controls.
- `mmo_liveops_engineer`: telemetry, feature flags, events, dashboards, observability, staged rollout, and incident readiness.
- `mmo_qa_reviewer`: final validation across correctness, networking, performance, security, data, tools, and release risk.
- `mmo_qa_fixer`: scoped remediation for QA findings.
