# MMO Specialist Roster

Use specialists only when their domain materially affects the task:
- `mmo_system_designer`: gameplay systems, player flow, scope, and plan.
- `mmo_engine_architect`: runtime boundaries, threading, memory, integration.
- `mmo_engine_programmer`: core engine/runtime implementation.
- `mmo_rendering_engineer`: rendering, shaders, GPU, visual performance.
- `mmo_animation_engineer`: animation, state machines, blending, events.
- `mmo_asset_pipeline_engineer`: imports, validation, build assets, content format.
- `mmo_world_streaming_engineer`: streaming, loading, LOD, world partition.
- `mmo_tools_engineer`: editor tools, content tools, developer workflow.
- `mmo_build_release_engineer`: packaging, patching, release, CI/CD.
- `mmo_engine_performance_engineer`: budgets, profiling, optimization.
- `mmo_server_authority_engineer`: authoritative gameplay, validation, simulation.
- `mmo_network_sync_engineer`: replication, prediction, reconciliation, protocol.
- `mmo_client_gameplay_engineer`: client feel, input, UI state, local prediction.
- `mmo_data_persistence_engineer`: saves, migrations, economy, data safety.
- `mmo_security_anticheat_engineer`: exploit prevention and abuse resistance.
- `mmo_liveops_engineer`: telemetry, rollout, feature flags, incidents.
