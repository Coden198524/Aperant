# MMO Quality Bar

Consider only domains touched by the task:
- Server authority and client trust boundaries.
- Network sync, prediction, reconciliation, latency, bandwidth, and protocol compatibility.
- Persistence, migration, economy integrity, rollback, and data privacy.
- Runtime budgets: frame time, memory, CPU, GPU, IO, loading, and network.
- Content pipeline, tools, assets, build/release, patching, telemetry, and live operations.
- Security, anti-cheat, abuse prevention, rate limits, and logging safety.

State unresolved domain risk explicitly instead of implying it was verified.
