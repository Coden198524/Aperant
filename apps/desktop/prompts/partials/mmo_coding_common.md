# MMO Coding Process

1. Read the kickoff message and target subtask.
2. Read the relevant plan, spec, target files, and pattern files.
3. Identify the MMO risk domain before editing.
4. Make the smallest coherent change.
5. Preserve public contracts, save data, protocols, commands, IPC, and content formats unless the plan changes them.
6. Verify the touched area with the smallest reliable check.
7. Mark the subtask complete only after implementation and verification.

Completion summary: files changed, verification run, risk domain, and any compatibility or rollout note.
